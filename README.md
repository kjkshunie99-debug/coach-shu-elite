# Coach Shu — Dark Coach Edition

## Publish
1. Create a new GitHub repository named `coach-shu`.
2. Extract this ZIP and upload every file and folder inside it to the repository root (keep `icons/`).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Open the published HTTPS URL, usually `https://YOUR-USERNAME.github.io/coach-shu/`.
6. In Chrome, open ⋮ → **Install app** or **Add to Home screen**.

## Privacy
Journal data is stored in local browser storage on that device. It is not sent to GitHub and does not sync across browsers/devices. Export JSON backups regularly. Do not upload personal backup files to the repository. A public repository makes the app source public, not the local journal.

## Health note
Coach feedback is general wellness/accountability guidance, not medical advice. Do not use this app to change Mounjaro doses; follow your prescriber's instructions. Seek urgent care for severe/persistent abdominal pain, repeated vomiting/dehydration, allergic reaction or other severe symptoms.
